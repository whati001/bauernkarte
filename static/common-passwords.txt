# Commonly-used / expected / compromised passwords, rejected on register
# and password change per NIST SP 800-63B §3.1.1.2 ("compare the
# prospective secret against a list of commonly-used, expected, or
# compromised values").
#
# READ BY BOTH SIDES, ON PURPOSE. `src/auth/password.rs` pulls it in at
# compile time with include_str!; `static/credential-policy.js` fetches
# it to drive the live checklist. One file so the hint the visitor sees
# and the rule the server enforces can't drift apart.
#
# Format: one entry per line, lowercase; `#` comments and blank lines
# ignored. Matching is case-insensitive on the trimmed password.
#
# This is a curated short list, not a breach corpus — it catches the
# passwords people actually reach for first, including the German and
# app-specific ones a generic English list misses. A full Have I Been
# Pwned range-query (k-anonymity, no password leaves the server) is the
# upgrade path if this ever needs to be exhaustive; it was left out to
# avoid making registration depend on an external service being up.
